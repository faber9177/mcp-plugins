# Faber for Claude Code

Faber connects Claude Code to your team's durable knowledge library. The plugin
supports artifact publishing and recall, proactive context suggestions,
knowledge capture, and an encrypted offline queue.

## Install

```bash
claude plugin marketplace add faber9177/mcp-plugins
claude plugin install faber-claude-code@faber-mcp-plugins
```

Ask Claude to set up Faber, then complete the browser sign-in. Existing valid
credentials are reused, and ordinary plugin upgrades preserve credentials,
queued work, and plugin data.

## Supported platforms

- macOS on Intel and Apple silicon
- Linux on amd64 and arm64

Windows is not included in this release.
