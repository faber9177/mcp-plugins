# Set up Faber for Claude Code

The matching Faber companion is included for supported macOS and Linux systems;
no separate download, Node.js installation, or administrator access is needed.

After installing the plugin, ask Claude to “set up Faber.” Claude opens a
browser when sign-in is required and securely reuses an existing connection
when possible.

Faber stores credentials in macOS Keychain or Linux Secret Service. Mutable
queue and knowledge-capture data stays in Claude's plugin data directory so
ordinary upgrades preserve it.
